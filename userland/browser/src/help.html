Forms

Select a field and press Enter: text fields open an editor at the bottom of the screen (Enter accepts, Esc cancels), check boxes and radio buttons toggle, drop-down lists open a menu. Press Enter on a button to submit the form. In a form without a submit button, pressing Enter in a text field submits it.

Captive portals

On a network that asks you to log in on a web page (hotels, trains, cafés), run browse --portal. It opens the login page found by netcheck and tells you once you have Internet access.

JavaScript is not supported: pages that need it may not work.
